# Import a job and learn while you build

Import a job or project (URL, text, md/txt/docx/pdf), then step through requirements, design, tasks, code, review and debugging. Learning mode explains why at each step. Personal data is masked before sending.

---

# 案件を取り込み、学びながら作る

案件・求人(URL・テキスト・md/txt/docx/pdf)を取り込み、要件→設計→タスク→コード→レビュー→デバッグと進めます。学習モードは各段階で理由を説明。個人情報は送信前に伏せます。
